# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

## Reading code in Zathura

Run `:CodeRead` or press `<leader>cP` (Space, c, Shift+p) to read the current
buffer as a clean A4 PDF in Zathura, including unsaved changes. Select lines in
Visual mode and press the same keys to read just that section. An explicit range
also works: `:10,50CodeRead`.

The PDF uses a light syntax theme with line numbers, a filename header, page
numbers, and wrapped long lines. Highlighting comes from Typst's language support
(including Python, C/C++, Rust, JavaScript, and more); it does not copy Neovim's
theme, semantic highlights, diagnostics, or virtual text. Unsupported languages
remain readable as plain text. Zathura preserves the PDF's colors even when the
desktop theme recolors other PDFs.

Full-buffer previews refresh on save while their Zathura window is open. Repeat
the command to refresh unsaved edits. Selected ranges are snapshots; repeat the
selection command to update them. Zathura opens in its own desktop window.

Use `:CodeExport ~/Documents/code.pdf` to keep a portable PDF, or
`:'<,'>CodeExport ~/Documents/section.pdf` for a selection. Export works over SSH
without Zathura. Existing files require `:CodeExport! path.pdf` to replace them.
Preview PDFs live in Neovim's cache under `code-reading/`; project directories
are left untouched. Typst is already provided by the shared Home Manager profile,
and Zathura by the desktop profile.

## Reading Markdown

In a Markdown buffer, run `:MarkdownPreview` or press `<leader>r` to render the
current buffer (including unsaved edits) as a PDF in Zathura. While the viewer is
open, saving the buffer refreshes the PDF automatically. Repeating the command
refreshes the existing preview; closing Zathura stops automatic conversion.

`:ReadmePreview` or `<leader>R` previews the nearest parent `README.md`.
`:MarkdownPreviewTerminal` keeps the Glow preview inside Neovim, including over SSH.
Zathura opens in its own desktop window; it cannot be embedded in a terminal buffer.

Pandoc and Typst are installed by the shared Home Manager profile; Zathura is in
the desktop profile. Generated PDFs live in Neovim's cache under
`markdown-preview/`, leaving project directories untouched. Standard Markdown,
tables, code blocks, images relative to the Markdown file, and math are rendered;
Mermaid diagrams and HTML-only layouts are not rendered as browser content.

## Python folder diagnostics

`:PyrightProject` checks saved Python files across the project and opens the
results in quickfix, including files you have not opened. Use `:cnext`/`:cprev`
to navigate. `:PyrightProject scripts` limits the scan to a relative path.
`:PyrightProject!` includes all upstream diagnostics.

Projects can opt into filtering inherited diagnostics with a
`.pyright-baseline.json` file at their root. Both push and pull LSP diagnostics
are filtered against matching messages, rules, ranges and unchanged upstream
source lines; unsaved edits are included. Inherited unused-code hints are hidden
only on unchanged lines. Projects without this file keep their normal diagnostics.
This custom format is generated by the thesis project's `scripts/check_types.py`
from its pristine upstream revision. Plain `pyright .` remains unfiltered.
